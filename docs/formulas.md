## Технічні примітки

- Відтворюваність ГА: `experiment.split` викликає `np.random.seed(seed)` + `permutation(N)` **до** генерації
  початкової популяції — так само, як legacy. Не змінювати порядок викликів, інакше результати зміняться.
- `exact: true` — побітово як legacy (`np.dot` по рядках). `exact: false` — матричне множення (×6 швидше);
  для ІХС дає ідентичні таблиці, але в загальному випадку може дати іншу траєкторію ГА.
- Прискорення ×3 порівняно з legacy без зміни результатів: у `on_generation` використовується вже обчислений
  `last_generation_fitness` замість повторного перерахунку фітнесу всієї популяції.

## Шкала значень і тип виходу (інтерфейс)

- `core/scale.py`: шкала проєкту `unit` [0, 1] або `sym` [−1, 1] — лише представлення значень концептів.
  Методи рахують у рідній шкалі (перфектність — [0, 1]; експертна НКК — [−1, 1]); x_unit = (x_sym + 1)/2.
  Ваги дуг не перетворюються. Таблиці звіту (Table_4, Table_6, I(Cᵢ)) виводяться у шкалі проєкту.
- Числовий вихід (`output.type: numeric` / `ExperimentConfig.output_type`): класів і порогів немає,
  хромосома — лише ваги, критерій — МНК (SSD), якість — MAD, MSE, R²; прогноз переводиться в одиниці
  вихідної змінної через min–max навчальних даних.

## Перевірка збіжності: правила виведення і порогові функції (розширення)

`core/convergence.py`, вкладка «Збіжність» на кроці «Використання» обох майстрів. Джерело — огляд
G. Nápoles et al., *A Review on Fuzzy Cognitive Mapping: Recent Advances and Algorithms*,
Big Data Cogn. Comput. 2026, 10, 22. Формули моделей дисертації не змінюються: базовий варіант («як у
моделі») — рекурентна формула статей **без порогової функції** + нормування (11) / max|x|.

| Огляд | Що | Код |
|---|---|---|
| (1)–(2) | класичне правило A⁽ᵗ⁾ = f(A⁽ᵗ⁻¹⁾W) | `Variant("kosko", f)` |
| (3)–(4) | розширене: f(k₁A W + k₂A), 0 < k₁, k₂ ≤ 1 | `Variant("extended", f)` |
| (5) | із самовпливом: f(A W + wᵢᵢA) (wᵢᵢ однаковий, бо діагональ W = 0) | `Variant("selfloop", f)` |
| (6)–(7) | квазінелінійне: φ·f(A W) + (1 − φ)A⁽⁰⁾ | `Variant("quasi", f)` |
| — | базова формула статей A⁽ᵏ⁺¹⁾ = A⁽ᵏ⁾ + (A⁽ᵏ⁾ − A⁽ᵏ⁻¹⁾)W, за потреби f після кроку | `Variant("native", f)` |
| табл. 1 | двозначна, ступінчаста (v), тризначна, tanh, сигмоїда (λ, h), масштабувальна X/‖X‖₂, експоненційна нормована sgn(x)(\|x\|/Σⱼ\|wⱼᵢ\|)^β | `activate` |
| розд. 3 | нерухома точка / цикл / хаос; єдина точка, якщо ‖Aᵢ − Aⱼ‖₂ < 1e-4 для всіх пар | `classify` |
| теорема 3 | сигмоїда: ‖W‖_F < 4/λ → єдина нерухома точка | `conditions` |
| теорема 6 | сигмоїда: λ < 4/N | `conditions` |
| теорема 10 | (6) з φ < 1: різні A⁽⁰⁾ → різні точки | `conditions` |

Додатково (не з огляду, виведено): для базової формули без f різниці D⁽ᵏ⁺¹⁾ = D⁽ᵏ⁾W, тож збіжність ⇔
ρ(W) < 1; для правил (1), (3), (5), (6) з ліпшицевою f — достатня умова стиску L·‖M‖₂ < 1 (теорема 3 —
її частковий випадок, бо ‖W‖₂ ≤ ‖W‖_F).

Протокол порівняння: ті самі початкові вектори (рядки даних / сценарії навчання), T кроків (за
замовчуванням — як у моделі: ІХС 30, УДС 50), вихід — стан на кроці T; «з нормуванням» — формула (11)
з межами, обчисленими тим самим варіантом (модель за даними), або ділення на max|x| (УДС). Базовий
варіант відтворює результати моделі (тести `tests/test_convergence.py`).

Спостереження (ІХС, налаштовані ваги): ρ(W) = 1.102 > 1 — базова формула не досягає стаціонарного стану
за 30 кроків, значення ростуть; правильні 62/65 забезпечує саме нормування (11). Автопідприємство:
ρ(W) = 0.58 (матриця статей 1, 4; ваги за Сааті — 0.64) — базова формула збігається для всіх сценаріїв.
